15. Media Architecture / Cloudinary Preparation
All images and media will eventually be stored using:
Cloudinary
Do not implement the Cloudinary upload system yet.
However, structure the application so Cloudinary can easily be integrated later.
Create an image abstraction/component such as:
<BlogImage
  src={article.image}
  alt={article.title}
/>
Keep image URLs in the article data rather than hardcoding them directly into components.
Later we should be able to replace:
/local-image.jpg
with:
https://res.cloudinary.com/...
without redesigning the components.
Configure the project architecture with future Cloudinary integration in mind.
